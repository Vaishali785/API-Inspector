API Inspector

Track API schema changes in real-time.

Example: /api/, /backend, /rest/v1

How to use
  1. Set API filters in the popup and click Save Settings.
  2. Open DevTools (F12).
  3. Reload the page (Hard reload recommended to avoid 304 cache).
  4. Go to the API Inspector tab to view tracked APIs.
Hints & Info
  • Only APIs with HTTP 200 status are tracked.
  • Cached requests (HTTP 304) are ignored.
  • Third-party APIs are not captured if the request referrer does not start with the current site's origin.
  • Changing filters does not remove previously captured APIs.
  • If filters were incorrect, use Clear APIs (for this site) and reload.
  • Theme changes apply after reopening DevTools.
